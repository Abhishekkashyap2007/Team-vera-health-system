# 🏥 VeraHealth – AI-Powered Smart Healthcare Platform

**Intelligent Healthcare, Secured for Life.**

VeraHealth is an AI-powered healthcare platform designed to make healthcare services more accessible, efficient, and convenient. It connects patients with healthcare professionals and provides digital health assistance, AI-based screening, and emergency support.

## 🚀 Key Features

- **AI Health Assistant:** Interactive AI-powered healthcare assistance.
- **AI Health Screening:** Preliminary AI-assisted health assessment.
- **Patient Dashboard:** Personalized patient portal.
- **Doctor Discovery:** Find and explore available doctors.
- **Hospital Finder:** Discover nearby healthcare facilities.
- **Online Consultation:** Healthcare consultation interface.
- **Emergency Assistance:** Emergency support and ambulance interface.
- **Doctor Dashboard:** Dedicated interface for doctors.
- **Admin Dashboard:** Administrative management interface.
- **Authentication:** User login and registration interface.

## 💻 Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Abhishekkashyap2007/Team-vera-health-system.git
cd Team-vera-health-system
```

### 2. Run the Frontend

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

### 3. Run the Backend

Open another terminal:

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

The backend will run locally at:

`http://localhost:8000`

API documentation:

`http://localhost:8000/docs`
